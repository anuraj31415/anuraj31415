# Anu

Software developer, mostly backend.

## Projects

[DeltaChecker](https://github.com/anuraj31415/deltachecker): a text diff tool in Next.js. Unified or side-by-side view, runs entirely in the browser.

[Typerator](https://github.com/anuraj31415/typerator): a 30-second typing test that plays a reaction clip based on your score (60% speed, 40% accuracy).

[repo-pulse](https://github.com/anuraj31415/repo-pulse): a Python CLI that summarises a git repo. Commits per day, most changed files, who's committing. Has `--since` and `--json`.

[envcheck](https://github.com/anuraj31415/envcheck): a Python CLI that compares `.env` with `.env.example` and reports missing, extra and empty keys.

[airing](https://github.com/anuraj31415/airing): a CLI that shows this week's airing anime with countdowns, using AniList's public API.

[tinykv](https://github.com/anuraj31415/tinykv): a small key-value store with a write-ahead log, crash recovery and compaction.
